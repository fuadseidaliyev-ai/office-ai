# ApocGo

Пост-апокалиптическая игра-выживание на дороге (вид сверху, пиксель-арт).
Вы едете на ржавом пикапе с собакой в кузове: объезжаете разрушенную дорогу,
обвалы и завалы, давите зомби и собираете три главных ресурса:

| Ресурс | Зачем |
|---|---|
| **Запчасти** | улучшение машины в гараже |
| **Еда** | питание водителя (клавиша `E`) |
| **Корм** | питание собаки (клавиша `Q`) |

Плюс канистры с **топливом** — без него рейс закончится посреди пустоши.

## Запуск

Нужен только браузер и любой статический сервер (ES-модули не грузятся с `file://`):

```bash
cd apocgo
node serve.mjs          # → http://localhost:8080
# или: python3 -m http.server 8080
```

Тесты (Node 18+, без зависимостей): `npm test`

## Управление

| Клавиши | Действие |
|---|---|
| `W` / `↑` | газ |
| `S` / `↓` | тормоз / задний ход |
| `A` `D` / `←` `→` | руль |
| `E` | поесть |
| `Q` | покормить собаку |
| `P` / `Esc` | пауза (в паузе `G` — прервать рейс) |
| `F3` | отладка: хитбоксы, FPS, сид |
| Сенсорный экран | левая/правая треть — руль, любое касание — газ |

## Игровой цикл

1. **Рейс** — доехать до радиовышки (1500 м на первом этапе, +500 м за каждый следующий).
2. По пути: ямы (урон + замедление), провалы асфальта, завалы, брошенные машины,
   упавшие столбы и деревья (твёрдые препятствия — удар зависит от скорости),
   бочки и шины (ломаются), зомби (на скорости ≥ ~16 км/ч сбиваются, на малой — грызут машину).
3. Обочина проходима, но машина там медленнее — а ресурсы часто лежат именно там.
4. Конец рейса: машина разбита, водитель или собака умерли от голода, кончилось топливо —
   тогда сохраняется только половина найденных запчастей. Доехали — всё ваше и открывается новый этап.
5. **Гараж** — тратим запчасти: Двигатель, Броня, Шины, Таран, Бак (по 4 уровня).

Прогресс хранится в `localStorage` (`apocgo.save.v1`). Сброс из консоли браузера:
`localStorage.removeItem('apocgo.save.v1')`.

## Архитектура

```
apocgo/
├── index.html          # canvas + загрузка src/main.js
├── serve.mjs           # мини-сервер без зависимостей
├── src/
│   ├── main.js         # сборка: loop + input + renderer + сцены
│   ├── engine/         # переиспользуемый движок, ничего не знает об игре
│   │   ├── loop.js       фиксированный шаг 60 Гц + render на каждый кадр
│   │   ├── input.js      ввод через «действия» (left, gas, eat…), клавиатура + тач
│   │   ├── renderer.js   низкое разрешение 480×270 для мира + чёткий UI-слой
│   │   ├── camera.js     следование, тряска, видимость
│   │   ├── particles.js  частицы (пыль, кровь, искры)
│   │   ├── scene.js      менеджер сцен
│   │   ├── text.js       текст/панели/полоски для UI
│   │   ├── math.js       AABB, круг-прямоугольник, clamp/approach
│   │   └── rng.js        детерминированный сид-RNG
│   ├── game/
│   │   ├── config.js     ВСЕ числа баланса: статы, апгрейды, спавн, голод
│   │   ├── generator.js  процедурная дорога по чанкам (чистые данные)
│   │   ├── world.js      симуляция рейса: столкновения, ресурсы, выживание
│   │   ├── truck.js      физика пикапа
│   │   ├── view.js       отрисовка мира по слоям
│   │   ├── sprites.js    процедурные пиксельные спрайты (кэшируются)
│   │   ├── hud.js        интерфейс рейса
│   │   └── save.js       сохранения
│   └── scenes/         # menu, play, garage, result
└── tests/              # node:test — движок, генерация, headless-симуляция рейса
```

Ключевые решения:

- **Логика отделена от отрисовки.** `World`, `generator`, `Truck` не трогают DOM,
  поэтому рейс можно прогонять в Node без браузера (см. `tests/game.test.js`).
- **Мир генерируется чанками** по 270 px из `(seed, номер чанка)`: одинаковый сид —
  одинаковая дорога. В каждой из трёх полос чанка не больше одного крупного
  препятствия, поэтому дорога всегда проходима (это проверяет тест).
- **Баланс — только в `config.js`.** Скорости, цены апгрейдов, частота спавна,
  скорость голода — всё меняется без правки логики.
- **Спрайты рисуются кодом**, но загружаются через функции `*Sprite()` — позже их
  легко заменить на PNG-атласы без изменений в остальном коде.

## Что дальше (идеи)

- Звук и музыка (`engine/audio.js`), спрайт-атлас вместо процедурных спрайтов.
- Собака как механика: лает на зомби, находит тайники.
- Остановки/лут-точки: выйти из машины и обыскать заправку или автобус.
- Оружие водителя (дробовик из референса), патроны как ещё один ресурс.
- Разные биомы и развилки маршрута (Riverton / Oakridge / Sanctuary), погода, ночь.
- Больше типов зомби: бегуны, толстяки-тараны, орды.
