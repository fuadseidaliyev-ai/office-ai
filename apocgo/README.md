# ApocGo

Пост-апокалиптическая игра-выживание на дороге (вид сверху, пиксель-арт в стиле
концепт-арта `tools/reference.png` — вся графика вырезана прямо из него).
Вы едете на ржавом пикапе с собакой в кузове: объезжаете разрушенную дорогу,
обвалы и завалы и собираете три главных ресурса (арт — `tools/pickups/`):

| Ресурс | Что делает |
|---|---|
| **Детали** | сразу чинят машину после ударов; лишние идут в запас — на улучшения в гараже |
| **Еда** | водитель ест сам, когда проголодается; без еды машина едет медленнее |
| **Корм** | собака ест сама; сытая собака **стреляет из дробовика** по зомби (патроны бесконечные), голодная — ждёт корм |

Броня теряется только при столкновениях с препятствиями; разбили машину — рейс окончен.


## Запуск

Нужен только браузер и любой статический сервер (ES-модули не грузятся с `file://`):

```bash
cd apocgo
node serve.mjs          # → http://localhost:8080
# или: python3 -m http.server 8080
```

Тесты (Node 18+, без зависимостей): `npm test`

## Управление

| Клавиши | Действие |
|---|---|
| `W` / `↑` | газ |
| `S` / `↓` | тормоз / задний ход |
| `A` `D` / `←` `→` | руль |
| `E` | поесть (или водитель ест сам) |
| `Q` | покормить собаку (или она ест сама) |
| `P` / `Esc` | пауза (в паузе `G` — прервать рейс) |
| `V` | экспериментальный вид сзади-сверху (по умолчанию — сверху) |
| `F3` | отладка: хитбоксы, FPS, сид (в виде сверху) |
| Вертикальный экран | телефон вертикально — дорога на всю ширину и видно дальше вперёд; повернули — игра перестраивается сама |
| Экранные кнопки | ◀ ▶ — руль, ГАЗ, ТОРМОЗ, ⏸ пауза (включаются сами на телефоне, `T` — вкл/выкл на компьютере); тап по строкам еды/корма в HUD — поесть/покормить; в гараже тап по строке — купить |

## Игровой цикл

1. **Рейс** — доехать до радиовышки (1500 м на первом этапе, +500 м за каждый следующий).
2. По пути: крупные препятствия — **поваленное дерево, разбитые машины, провал асфальта,
   каменный завал** (арт из `tools/obstacles/`). Каждое стоит **слева, по центру или
   справа**; удар считается по нарисованной форме (маски в `src/game/masks.js`), сила — от
   скорости. Зомби на скорости ≥ ~15 км/ч сбиваются, на малой — грызут машину.
3. За пределы асфальта выехать нельзя; все ресурсы лежат на дороге.
4. Конец рейса: машина разбита, водитель или собака умерли от голода, кончилось топливо —
   тогда сохраняется только половина найденных запчастей. Доехали — всё ваше и открывается новый этап.
5. **Гараж** — тратим запчасти: Двигатель, Броня, Шины, Таран, Бак (по 4 уровня).

Прогресс хранится в `localStorage` (`apocgo.save.v1`). Сброс из консоли браузера:
`localStorage.removeItem('apocgo.save.v1')`.

## Архитектура

```
apocgo/
├── index.html          # canvas + загрузка src/main.js
├── serve.mjs           # мини-сервер без зависимостей
├── assets/             # PNG-спрайты и текстуры (генерируются из концепт-арта)
├── tools/
│   ├── reference.png     концепт-арт — источник всей графики
│   └── build_assets.py   вырезка объектов (rembg), декали, бесшовные текстуры
├── src/
│   ├── main.js         # сборка: loop + input + renderer + сцены
│   ├── engine/         # переиспользуемый движок, ничего не знает об игре
│   │   ├── assets.js     загрузка картинок
│   │   ├── loop.js       фиксированный шаг 60 Гц + render на каждый кадр
│   │   ├── input.js      ввод через «действия» (left, gas, eat…), клавиатура + тач
│   │   ├── renderer.js   буфер мира 1600×900 + чёткий UI-слой 480×270
│   │   ├── camera.js     следование, тряска, видимость
│   │   ├── particles.js  частицы (пыль, кровь, искры)
│   │   ├── scene.js      менеджер сцен
│   │   ├── text.js       текст/панели/полоски для UI
│   │   ├── math.js       AABB, круг-прямоугольник, clamp/approach
│   │   └── rng.js        детерминированный сид-RNG
│   ├── game/
│   │   ├── config.js     ВСЕ числа баланса: статы, апгрейды, спавн, голод
│   │   ├── generator.js  процедурная дорога по чанкам (чистые данные)
│   │   ├── world.js      симуляция рейса: столкновения, ресурсы, выживание
│   │   ├── truck.js      физика пикапа
│   │   ├── view.js       отрисовка мира сверху
│   │   ├── view3d.js     вид сзади-сверху: дорога в перспективе (mode 7) + спрайты по глубине
│   │   ├── art.js        реестр PNG из assets/
│   │   ├── sprites.js    процедурные спрайты для того, чего нет в арте (иконки лута, ямы)
│   │   ├── hud.js        интерфейс рейса
│   │   ├── touchpad.js   экранные кнопки: руль, газ, тормоз, огонь, пауза
│   │   └── save.js       сохранения
│   └── scenes/         # menu, play, garage, result
└── tests/              # node:test — движок, генерация, headless-симуляция рейса
```

Ключевые решения:

- **Логика отделена от отрисовки.** `World`, `generator`, `Truck` не трогают DOM,
  поэтому рейс можно прогонять в Node без браузера (см. `tests/game.test.js`).
- **Мировые единицы = пиксели концепт-арта**, поэтому спрайты рисуются в родном размере,
  а масштаб машины, зомби и дороги совпадает с картинкой.
- **Мир генерируется чанками** по 900 px из `(seed, номер чанка)`: одинаковый сид —
  одинаковая дорога. В каждой из трёх полос чанка не больше одного крупного
  препятствия, поэтому дорога всегда проходима (это проверяет тест).
- **Баланс — только в `config.js`.** Скорости, цены апгрейдов, частота спавна,
  скорость голода — всё меняется без правки логики.
- **Графика из концепт-арта.** `tools/build_assets.py` вырезает объекты нейросетью
  удаления фона (rembg), вытаскивает граффити/трещины/кровь цветовыми ключами и
  собирает бесшовные текстуры асфальта и земли из чистых участков картинки.
  Пересобрать: `pip install pillow numpy "rembg[cpu]" && python tools/build_assets.py`.

## Что дальше (идеи)

- Звук и музыка (`engine/audio.js`), спрайт-атлас вместо процедурных спрайтов.
- Собака как механика: лает на зомби, находит тайники.
- Остановки/лут-точки: выйти из машины и обыскать заправку или автобус.
- Анимация ходьбы зомби (сейчас один кадр + покачивание) и персонаж-выживший на ногах.
- Разные биомы и развилки маршрута (Riverton / Oakridge / Sanctuary), погода, ночь.
- Больше типов зомби: бегуны, толстяки-тараны, орды.
